# QA & AI Learning Guide — v6 Bootcamp comparison

This revision was built directly from v5 and compared against the full 378-lecture outline of **The Complete Software Testing 2026 Bootcamp – All-In-One Testing Guide**.

## Major additions

- Software/application fundamentals: single-tier, multi-tier, multi-role, multi-channel systems.
- Requirements lifecycle, development models, software-team roles, and design review.
- Manual QA execution workflow, practical defect reporting, AI-assisted test design, test-plan templates, progress/completion reporting.
- Jira, Trello, Qase, Zephyr Scale, Azure DevOps, and Confluence.
- Agile values/principles, Scrum, user stories/INVEST, Planning Poker, burn-down/burn-up, velocity, Kanban, stabilization/hardening.
- Web/Internet foundations, XML, SOAP, deeper Postman workflows.
- Performance test types, load profiles, statistics, Apache JMeter, BlazeMeter, correlation, timers/think time, CLI execution, controllers, sampler-error behavior.
- DBMS/SQL command families, CRUD, primary/foreign keys, ERDs, cardinality, entity/attribute types.
- Java foundations, IntelliJ IDEA, Maven, Selenium WebDriver, locator/control patterns, TestNG, Katalon Studio.
- Detailed mobile testing: app/device types, inputs, orientation, interruptions, permissions, power, notifications, connectivity, installability, interoperability/co-existence, analytics/usability.
- White-box coverage: statement, decision, condition, MC/DC, path, loop; plus pairwise testing.
- ISTQB/A4Q and adjacent certification context, T-shaped development, crowdtesting, CV/cover letter and interview preparation.
- Five hands-on labs: manual QA, Postman API, JMeter, Selenium/TestNG, and test management.
- axe DevTools profile and extended accessibility-tool coverage.
- Expanded acronym reference (DBMS, ERD, CRUD, DDL/DML/DQL/TCL/DCL, JDK/JRE, ISTQB, CTFL, MC/DC, INVEST, etc.).
