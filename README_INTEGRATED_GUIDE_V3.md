# Integrated Learning Guide v3

This version moves all 62 technology/language/framework/protocol/platform profiles into the main body of the QA & AI Learning Guide.

For every profile, the guide includes:

- what it is;
- its main characteristics;
- its relevance to QA / automation;
- what the name or acronym means (including explicit notes when a name is not an acronym).

Appendix G is now an alphabetical index linking to the integrated profiles instead of duplicating them.

## Validation

- 62 technology profiles integrated exactly once
- 0 duplicate HTML IDs
- 0 broken internal anchor links
- every profile contains Definition, Main characteristics, QA / automation relevance, and Name / acronym
